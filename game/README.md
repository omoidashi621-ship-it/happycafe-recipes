# 世界樹の図書館

ブラウザで遊ぶ、みんなで集まれる異世界の図書館(試作版)。
アバター選択 → ジョブ選択 → 図書館を移動 → 同時ログイン中の人とチャット。

## 試す(ローカルモード)

```
cd game
python3 -m http.server 8000
```
`http://localhost:8000` を開く。ローカルモードでは**同じブラウザの別タブ同士**だけが見えます。

## 操作

| 操作 | 方法 |
|---|---|
| 移動 | 矢印キー / WASD / クリック・タップ |
| チャット | Enter で入力 → Enter で送信 |
| 表情 | 画面下の表情バー、または数字キー `1`〜`0` |
| ジョブのエモート | ✨ ボタン |
| ズーム | マウスホイール |
| 魔法陣を調べる | 近づいてスペースキー(ミニゲームは準備中) |

### 表情
通常 / にっこり / 大笑い / 怒り / 悲しい / 驚き / ウィンク / ハート / ねむい / 照れ の10種類。
チャットの文面からも自動で変わります(「ありがとう」→にっこり、「あはは」→大笑い、「えっ!!」→驚き など)。
45秒間操作しないと眠ります。後ろ向きに歩いていても表情が見えるよう、画面左上に自分の顔、チャットの各発言に話し手の顔アイコンを表示します。

## みんなで遊ぶ(Firebase)

1. https://console.firebase.google.com でプロジェクトを作成(無料の Spark プラン)
2. 「Authentication」→「Sign-in method」→ **匿名** を有効化
3. 「Realtime Database」→ データベースを作成(リージョンは asia-southeast1 など)
4. 「Realtime Database」→「ルール」に `database.rules.json` の内容を貼って公開
5. プロジェクトの設定 → 「マイアプリ」→ ウェブアプリを追加し、表示された設定値を `js/firebase-config.js` に貼る(`databaseURL` も必須)
6. 公開: `npm i -g firebase-tools` → `firebase login` → `firebase init hosting`(公開ディレクトリは `game`)→ `firebase deploy`

## 構成

| ファイル | 役割 |
|---|---|
| `js/main.js` | 画面遷移、入力、描画ループ、チャット、表情 |
| `js/net.js` | 通信層。`LocalNet` / `FirebaseNet`。自前サーバーに移すときはここだけ差し替える |
| `js/world.js` | マップ、当たり判定、背景・世界樹の描画、光の演出、魔法陣(ミニゲーム入口) |
| `js/avatar.js` | アバター描画(ベクター)。表情・まばたき・歩き・髪型・ジョブ装備 |
| `js/gfx.js` | 描画の共有部品(色、毛束・根のパス、高解像度レイヤー、光の玉) |
| `js/jobs.js` | ジョブ定義 |

絵はすべてコードで描いているので、画像ファイルはありません。ジョブや髪型、背景の飾りはコードを足すだけで増やせます。
